# 项目实施错误记录

## 2026-07-30：交付了缺少 custom-protocol 的 EXE

- 现象：直接运行 `desktop-pet-learning-companion.exe` 显示 `404 - Nothing matches the given URI`。
- 根因：Tauri CLI 因当前终端找不到 `cargo` 而失败后，改用普通 `cargo build` 生成并覆盖了 EXE；该命令未启用 `tauri/custom-protocol`，独立运行时没有从 `frontendDist` 加载内嵌页面。
- 禁止重犯：原生交付必须通过 `tauri build`，或显式使用 `cargo build --features custom-protocol`。验证必须看到真实宠物与任务界面，不能只以“进程仍在运行”判定成功。

## 2026-07-30：双击后只见 CMD，格格恢复到错误屏幕

- 现象：用户双击调试 EXE 后只看到 CMD 窗口，看不到格格。
- 根因一：Windows 二进制没有声明 GUI 子系统，调试构建会保留控制台窗口。
- 根因二：本地状态中的显示器 ID 已过期，但坐标仍属于当前主屏；位置恢复错误地优先相信旧显示器 ID，把格格钳制到了另一块屏。
- 禁止重犯：双击验证必须同时确认没有控制台窗口、格格出现在当前坐标所属屏幕；多显示器测试必须覆盖“显示器 ID 与坐标归属冲突”。
