# 鸡兔同笼课件重做设计方案

本方案以 `docs/鸡兔同笼参考视频逐帧复原记录.md` 为教学依据，把视频中的有效状态变化改造成教师点击控制的网页课件。目标不是复制视频文件或品牌外观，而是完整保留“讲师一句—画面一动—算式命名—停住”的教学节奏。

## 1. 教学合同

- 目标年级：四年级。
- 已有知识：乘法、除法、加减法、鸡有 2 条腿、兔有 4 条腿。
- 暂不引入：字母方程、二元一次方程、代数消元。
- 核心卡点：学生会套 `差÷2`，但不知道“2”来自哪里，也不理解商为什么就是兔的只数。
- 可观察证据：同一个头先配 2 条基础腿，再补 2 条腿就变成 4 条腿；每完成一次这种变化，假设腿数就向实际腿数靠近 2 条。
- 主推理链：完整读题 → 头的模型 → 全部按少腿类型假设 → 比较腿数 → 看一次调整 → 用总差除以单次变化 → 求另一类 → 代回检验。
- 反向验证：把所得两类数量代回头数和腿数。
- 拓展思考：把“鸡和兔”换成“一腿兽和四腿蛇”，检验同一结构是否仍成立；最后抽象为“头和与腿和”。

## 2. Design Read

- Artifact：教师控制的单舞台网页课件。
- Audience：教师讲解，四年级学生观察。
- Teaching job：让“全部按少腿类型计算—找差—逐个调整”的关系直接可见。
- Mood：温暖纸面、轻板书、克制而清楚。
- Density：低到中；一个时刻只突出一个数学动作。
- Motion：中；只有绘制、抽取、变换、强调和框选发生局部动画。
- Base system：项目 `DESIGN.md`，并借用 Paper 参考中的纸面材质与清晰层级。
- Interaction reference：用户提供视频的讲师同步推进方式。
- Keep：左侧已知量锚点、右侧连续推理、先看动作再出现算式、蓝色少腿型、紫色多腿型、红色差量和结构框。
- Adapt：改为项目字体、颜色和可访问控件；把时间轴改成教师点击的教学停靠点；用原生 SVG 生成数学对象。
- Avoid：水印、角色造型、手写字体、品牌构图、装饰卡片、常驻侧栏、进度条、整页淡入淡出、自动连播。
- Lesson-specific visual：同一排“头—基础腿—补充腿”对象贯穿假设、比较、调整与检验。

## 3. Visual Build Sheet

- Mathematical focus：每把一个少腿对象改成多腿对象，总腿数会增加固定数量。
- Visual thesis：一张稳定的浅暖纸面上，用圆和腿线完成板书式推理。
- Scene layers：低对比纸面 / 左侧题目条件 / 右侧头与腿模型 / 括号、箭头和算式 / 底部导航 / 局部强调反馈。
- Object grammar：圆形头、深色 3px 轮廓、蓝色基础腿、紫色补充腿、轻微纸片阴影；头的位置固定，腿和标注随推理变化。
- Color jobs：
  - 深棕：正文与轮廓；
  - 蓝色：少腿类型和假设基准；
  - 紫色：多腿类型和补充腿；
  - 青绿：未知数与提问；
  - 红色：单次增加量、关键数值圈线和方法结构框；
  - 灰棕：已讲过但暂非焦点的信息。
- Motion language：
  - stable frame：页头、舞台、左侧条件区和底部导航不重建、不淡入；
  - hover：按钮轻微抬起；
  - press：按钮下压并缩短阴影；
  - mathematical change：腿线绘出、对象下移、箭头延伸、局部数字短暂放大；
  - incorrect attempt：本课没有学生作答输入，不设置无意义错误动画；
  - reveal：新证据在 220–300ms 内绘制或出现；
  - reduced motion：取消位移和绘制过程，直接显示终态。
- Opening state：舞台内完整出现鸡、兔、10 只、26 条腿和“各有多少只”，不出现方法或答案。
- Core reasoning state：35 个头的压缩表示、全鸡 70 条腿、实际 94 条腿、差 24 条、一次调整 `+2` 同屏对应。
- Final verification state：迁移题完整算式保留，红圈标出 30 个头和 90 条腿，标题落在“假设法解鸡兔同笼—头和与腿和”。
- Desktop fit rule：课堂外壳固定为 `100dvh` 五行网格；舞台使用 `minmax(0, 1fr)`，SVG 按比例缩放；1366×768 与 1440×900 不产生页面纵向滚动。
- Avoid：常驻说明栏、分步信息卡、装饰角色、粒子、循环动画、背景漂移、霓虹和玻璃拟态。

## 4. 场景驱动六项交付

### Persistent Scene

浅暖纸面与左右分区始终固定。左侧是题目对象和总量锚点，右侧是同一套圆头、腿线、括号、箭头和算式。正式题与迁移题只替换数据和对象名称，不重新发明版式。

### State Delta Map

1. 小例题：完整读题 → 强调头数 → 画 10 个头 → 单看鸡腿 → 单看兔腿 → 全当鸡 → 得到 20 条 → 比较 26 条 → 得到差 6 条 → 看一次 `+2` → 连续三次调整 → 得到 3 兔 7 鸡 → 检验。
2. 倒回过程：擦去答案 → 回到全鸡 → 依次画出三条调整箭头 → 红框提取核心变化。
3. 正式题：完整读 35/94 → 压缩画头 → 全当鸡得 70 → 比较得 24 → 抽出一个单位看 `+2` → `24÷2=12` → `35−12=23` → 检验 94。
4. 方法命名：按假设、比较、调整、检验的顺序逐个画红框，最后出现“假设法”。
5. 迁移题：完整读 30/90 → 全当一腿兽得 30 → 比较得 60 → 一次调整 `+3` → 求 20 只四腿蛇和 10 只一腿兽 → 检验。
6. 抽象：标题扩展 → 强调比较 → 强调检验 → 圈出头和 → 圈出腿和 → 落到一般题型名称。

### Narration Sync

每个页面步骤对应中英文演讲稿中的一个停靠点。老师先提问并停顿，再点击；页面只完成该步动作，算式命名动作后停住。舞台空白处、“下一步”、右方向键、PageDown 和空格都只推进一步。

### Representation Change

真实鸡兔图标只负责建立情境，随后通过可见过渡抽象为圆头和腿线；正式题用省略号压缩数量，但保留圆头和腿线语法；迁移题只更换对象名称和每只腿数，保持同一推理结构。

### Motion Meaning

- 画圆：把“只数”变成“头数模型”。
- 画基础腿：执行“全部按少腿类型假设”。
- 补腿：把一个少腿对象调整为多腿对象。
- 箭头和 `+2/+3`：说明一次调整的方向与变化量。
- 数字放大：把当前需要比较或相除的量拉到焦点。
- 红框：在完整解题后抽取方法结构。
- 红圈：把具体动物题抽象为头和与腿和。

### Reduced Motion

在 `prefers-reduced-motion: reduce` 下取消位移、缩放和路径绘制动画，所有新对象直接显示在终点；颜色、位置、文字和框线仍完整表达同一数学意义。

## 5. 三个静态验收状态

1. 开场：10 只动物、26 条腿和所求问题在舞台内完整可见，答案未出现。
2. 核心：35 个头压缩模型、70、94、24 和一次 `+2` 调整关系同时清楚，没有遮挡。
3. 结尾：迁移题结果与检验保留，30 个头和 90 条腿被红圈标记，最终方法标题完整可见。
