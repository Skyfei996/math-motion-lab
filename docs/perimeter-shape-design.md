# 几何画布（自由拼线段）：周长实验设计

## 目标与边界

用户需要可自己操作的自由画布，而非固定翻页课件。页面名为「几何画布」，无标题栏；返回目录与语言切换收进「更多」菜单。可输入任意正数长度，持续添加独立线段，没有固定条数上限；线段长度数字可显示或隐藏，线身只显示数字而不显示单位。圆形端点大小可设，保留更大的透明抓取区域。拖动线身可按模式搬动单条或整个连接组；空白处拖框多选后可整组移动、删除；端点沿线段方向拖动可改变边长，斜向拖动可旋转并带动已连接线段；「连线」模式下抓住端点向外拖动可补一条新线段，松手时靠近其他端点会吸附。接近水平或垂直时轻微吸附，其他角度保持可选；端点靠近时吸附。尺寸弹窗可一次创建多份正方形、长方形、三角形、梯形、圆或椭圆，初始位置错开，再逐个拖动。支持操作撤回、所选对象复制和错位粘贴；所选线段或图形可从 10 色预置色板选色或自定义颜色，并设置线宽、实线或虚线。选中对象可保存进素材库（localStorage 持久化，跨会话保留），素材库条目可随时放入当前视野中央或删除；也可保存整张画布。圆与椭圆是独立曲线图形，显示近似周长。未闭合直边图形只称「线段总长」，闭合后才称「周长」。图形名称、周长、算式和错误提示在画布下方的窄状态栏呈现，只在有选中图形或输入错误时出现；不在画布上叠加说明浮层。线段计数为左下角常驻小标记。

保存整张画布时弹出名称输入框，默认名称可修改；取消或输入空名称不会新建素材。素材库条目提供改名操作，名称与几何内容一起持久保存。重名时自动补数字后缀。

线段可按份数等分、按指定各段长度拆分，也可切换「点击拆分」模式在线身指定位置产生新端点。拆分保持整段的几何位置和总长度；新端点可继续作为连线起点，形成三岔连接。按住 Shift 可逐条选中多段；合并仅接受同一直线、首尾相接、样式相同且中间端点没有其他分支的线段，避免吞掉连接点。带分支的连接组仍可在「移动图形」模式整体移动，但不将它误称为单条直线。闭合轮廓的一条边被拆开后，仍以原有转角识别图形并保持周长；有分支的连接组按线段总长显示，不把分支计入封闭周长。拆分、合并与原有拖动、撤回、复制粘贴、素材库共用当前线段数据。

闭合直边图形、圆与椭圆可设置独立于轮廓线的填充色：沿用 10 色快捷色板，支持颜色输入和清除填充。线段构成的多个相邻封闭区域会分别生成可点击的填充面，可为共用边的两侧独立上色；未选择封闭图形或区域时填充控件不可用。填充样式跟随图形参与撤回、复制粘贴与素材库保存；旧素材没有填充字段时保留原有浅色默认显示。分支图中的区域周长按所点区域的边界显示，原有整组线段总长判断保留。Ctrl 拖动线身时，首次有效移动按主要方向锁定水平或垂直轴，松开 Ctrl 后恢复自由移动；Ctrl 连线长度取最近的整厘米，优先于端点吸附；Ctrl 沿线拖端点则把长度变化量吸附到整厘米，保持原有斜向旋转规则。

线段长度与快捷图形尺寸接受正数，不设置固定厘米上限和半厘米步长。1 厘米恒等于 32 像素、一个背景网格；SVG 视野按缩放比例换算，网格随缩放同步，不按内容自动缩小。新对象按行错开放置；超出视野时用滚轮或触控板滚动平移、Ctrl＋滚动以指针为中心缩放、空格拖动或鼠标中键拖动查看；右下角缩放控件提供放大、缩小、100% 复位和「适应」全览，缩放范围 25%～400%。低频外观设置（颜色、色板、线宽、端点大小、线型、长度数字开关）收进「样式」面板，复制、粘贴、保存整张画布、清空、返回目录和语言切换收进「更多」菜单。工具栏另有「快捷键 ?」按钮，列出 N／Shift+N、1／2／3、Ctrl+A／C／V／Z、L、S／B／M、F、缩放、空格拖动、Delete 和 Esc 等键位。画布快捷键在尺寸输入、弹窗和中文输入法组合期间暂停，Esc 优先关闭弹窗或面板，再退出连线或取消选择。批量创建数量须为正整数。三角形和梯形尺寸必须能构造有效图形。长度不满足多边形围合条件、图形自交或边长误差过大时，不宣称已围合。

## 2026-10-20：文字、半圆与图片切割

本轮沿用现有纸面格网、工具栏、样式面板与窄状态栏。用户已确认以下功能范围：文字工具在任意点击位置插入文字或 Unicode 数学符号，双击编辑，支持字号、颜色和现有对象操作；快捷图形增加带直径边的闭合半圆，输入半径并按 `(π＋2)r` 计算周长；本地图片保持比例插入，直线切割所选图片/图片块，可连续切多刀。文字与切片共用选中、平移、旋转、多选、复制粘贴、撤回和素材库，兼容旧素材。

切割只改变凸多边形边界，保留源图片与局部坐标；旋转后把切割线变换回局部坐标再计算。未穿过内部、擦边或无长度的切割不产生新对象或撤回记录。每一块保留对应图像，可继续切割；面积守恒，旋转与平移不改变周长。文字按字面显示，不解释 HTML。图片保存在本机素材库中，容量不足时显示错误。

验收：中文与数学符号任意位置输入、双击编辑与输入法快捷键隔离；半圆半径 3 厘米时周长约 15.4248 厘米；图片横切、斜切、多次切割、旋转后切割及边界擦过；切片原位纹理拼合、面积守恒、单块与混合对象旋转平移；撤回、复制、素材库重载、旧素材兼容与保存失败提示。两种桌面尺寸下，新增入口收进紧凑的插入工具组，保证画布可用面积，检查中英文按钮、面板和弹窗无遮挡、无页面溢出。

## 2026-10-20：图层顺序

沿用现有纸面格网和下拉菜单，在工具栏增加「图层 ▾」，含「上移一层」「下移一层」「置于顶层」「置于底层」。连接的线段组作为完整图形，占同一层，填充、轮廓、数字和端点一起移动；圆、半圆、文字和每块图片各占一层。选中图形的任意边时，图层操作作用于整个连接组。多选保持内部先后顺序，单步移动跨过一个未选层。无选中或不能继续移动时禁用相应操作；无变化不记录撤回。

新建对象置顶；拆分继承层级，连接两个线段组时采用较高层。层级支持撤回、复制粘贴、保存图形和保存整张画布。重新放入素材或粘贴时整体置于当前对象前方，内部顺序不变；旧素材仍可读取。旋转中心、旋转手柄和切割辅助线保持在所有图形前方。

验收：混合类型重叠时四个层级操作和点击命中正确，整个直边图形同时遮挡/被遮挡，多选顺序稳定，边界按钮禁用且不产生撤回，复制与素材重载保留顺序。1366×768、1440×900 中英文图层菜单无越界，按钮各状态对比度达到 4.5:1。

本轮图层验证：模型、界面模拟、课程包检查及真实 Edge 浏览器回归通过。浏览器以混合的直边图形、圆、文字和图片检查绘制顺序、鼠标命中、整图填充/边线/标注/端点分组、边界按钮与撤回、多选复制、素材保存重载和旧素材兼容。已人工检查两种桌面尺寸的中英文图层菜单截图，无新增脚本错误。

## 2026-10-20：半圆扩展为扇形

沿用现有画布视觉和添加图形弹窗，将「半圆」选项替换为「扇形」，输入半径与圆心角（°），默认半径 3 厘米、圆心角 180°。圆心角接受大于 0°、不超过 360° 的有限数值，支持小数；90°、180°、270° 分别占整圆的 1/4、1/2、3/4。对象旋转角与圆心角独立保存。旧素材的半圆继续作为 180° 的闭合图形读取。

不足 360° 时，轮廓为圆弧和两条半径，周长为 `圆心角 ÷ 360 × 2 × π × 半径 + 2 × 半径`；360° 时绘制整圆，不出现半径边，周长为 `2 × π × 半径`。选择框、批量放置、适应视野和旋转使用扇形真实边界。填充、图层、平移、旋转、撤回、复制粘贴和素材保存沿用现有操作。

验收：半径 3 厘米时，90°、180°、270°、360° 的周长分别约为 10.7124、15.4248、20.1372、18.8496 厘米；小数角度保留，空值、零、负数与超过 360° 被拒绝且不产生对象或撤回。检查大于 180° 的长弧、360° 无内边、旋转后的真实边界、复制与素材重载保持圆心角、旧半圆兼容，以及两种桌面尺寸下中英文输入弹窗无遮挡。

验证记录：数学模型、界面模拟、扇形模型、课程包校验和真实 Edge 浏览器回归通过。以密集采样对照旋转扇形边界，并检查原椭圆极值；浏览器验证 90°、180°、270°、360°、22.5° 的绘制、周长、填充区域、适应视野、旋转撤回、复制、素材重载及旧半圆兼容。无效半径和角度不生成对象或撤回记录。已检查 90°、270°、360° 画布及 1366×768、1440×900 中英文弹窗截图，无越界或新增脚本错误。

## Design Read

- Artifact：家长或教师与孩子共用的桌面几何实验画布，配双语打印讲稿。
- Audience：三至四年级；已经认识线段、四边形和周长。
- Teaching job：孩子亲手移动定长线段，分清「线段总长」与「封闭图形周长」，观察形状变而周长不变。
- Mood / density / motion：温暖纸面课堂、低文字密度、拖动直接跟手；没有自动播放。
- Base system：项目 `DESIGN.md`；参考 `paper/DESIGN.md` 的清楚纸面层次。
- Interaction reference：项目现有几何课的定长标注与键盘焦点样式。
- Keep：高对比工具、可读长度标注、稳定的几何舞台。
- Adapt：把课件导航换为自由画布；仅把必要的数值和错误收在画布下方的窄状态栏。
- Avoid：固定「下一步」、自动演示、装饰性动画和结果卡堆叠。
- Lesson-specific visual：同一画布上的独立线段和快捷图形，由孩子选择、摆放、围合与比较。

## Visual Build Sheet

- Mathematical focus：每条边不变时，封闭图形的周长等于同一组边长之和。
- Visual thesis：浅格纸上的可抓取定长线段。
- Scene layers：低对比格纸 / 独立定长线段、曲线与端点 / 可切换的数字标签 / 选择框与选中描边 / 闭合图形填充 / 画布下方的图形与周长状态栏 / 右下角缩放控件。
- Object grammar：默认青绿色线段、直径 6 像素的白色端点和透明大抓取区；用户可改变对象颜色、线宽、端点大小和虚实；棕金描边表示选中，标签随线段位置移动。
- Color jobs：默认青绿表示数学对象，用户颜色只作用于所选对象，金色描边表示选中，蓝色表示添加操作，灰色表示未围合，玫红仅表示需要修正的输入。
- Motion language：抓线身独立平移，拖端点转向或带动已连接线段；接近水平或垂直时轻微吸附；数学舞台和工具栏不闪烁。
- Opening state：空画布、长度输入和「添加线段」；提示用户自己开始。
- Core reasoning state：可选单条、连接组或框选多个对象；各线段可单独摆放，端点接近时吸附；未闭合时只显示线段总长。
- Final verification state：闭合形状可继续拖动；图形名称可能改变，长度标签与周长算式保持相同。
- Desktop fit：页面用 `100dvh` 网格，工具和结果占固定小行，画布可收缩；目标视口为 1366×768 与 1440×900。
- Avoid：不设翻页、不把开放线段误报为周长、不用颜色作为唯一状态信息。

## 场景与讲解

- Persistent Scene：用户新增的线段与图形始终留在同一画布；端点、数字标签开关和当前连接关系持续可见。
- State Delta Map：空画布 → 添加线段或批量创建尺寸图形 → 调整颜色、线宽和线型 → 切换标签与移动模式 → 选择单条、连接组或框选多个对象 → 围合和变形 → 删除选中对象。
- Narration Sync：教师依次提问「长度变了吗」「什么时候叫周长」「形状变后哪几个数没变」，操作和停顿见双语讲稿。
- Representation Change：画面始终用线段表示边；画布下方状态栏只在闭合后显示「周长」。
- Motion Meaning：线身移动或端点斜向拖动表示摆放变化，端点沿线拖动表示改变边长；吸附表示首尾相接；长度标签随实际边长变化。
- Reduced Motion：没有持续动画；减少动画时所有几何状态与文字证据仍完整。
