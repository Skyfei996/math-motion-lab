# 桌面学习宠物 Motion Bible

> 状态：V0.1 动作时间轴基线
> 目标平台：Windows 桌面
> 目标用户：6～10 岁
> 制作帧率：24 fps
> 运行帧率：60 fps 插值；逻辑事件仍绑定制作帧

## 1. “逐帧设计”的交付口径

- 本文中的 `F00–F05` 表示起止帧均包含在内；相邻区间必须首尾连续，不能存在未定义帧。
- 每个区间写明姿势变化、道具、阴影、粒子、音效或程序事件。区间内部由动画工具按指定缓动补间，不额外发明动作。
- `hold` 表示保持上一帧姿势；`step` 表示不补间；`linear` 表示线性；`ease-out` 表示快速启动后减速；`ease-in` 表示缓慢启动后加速；`ease-in-out` 表示两端减速。
- `wait@Fxx(event)` 表示时间轴到 Fxx 后停在该帧，不消耗后续制作帧；收到括号内程序事件后才从 Fxx+1 继续。等待期间只允许 P0、当前输入和取消操作。
- 循环动作只循环明确标注的帧段。进入段和退出段不参与循环。
- 所有位移以 `ground_anchor` 为基准；所有缩放默认保持脚底或悬浮中心不漂移。
- 每组动作必须拥有：唯一 ID、总帧数、循环段、触发条件、优先级、中断方式、结束姿态和减少动态替代方案。
- 动画实现不得用“自然过渡”“适当延迟”等不可验收描述替代本文数值。

## 2. 锚点与通道

### 2.1 角色锚点

| 锚点 | 用途 |
|---|---|
| `ground_anchor` | 脚底中心；团团使用悬浮中心的垂直投影 |
| `head_hotspot` | 摸头和视线目标 |
| `drag_anchor` | 拖拽提起点 |
| `item_anchor_l` / `item_anchor_r` | 左右手、爪或丝带手臂持物点 |
| `bubble_anchor` | 字幕、快捷卡和思考符号连接点 |
| `signature_anchor` | 尾尖、天线、新芽或云旋的特效点 |
| `shadow_anchor` | 软阴影中心 |

### 2.2 可动画通道

- 角色：`translateX/Y`、`rotate`、`scaleX/Y`、眼睛视线、眼睑、嘴型、标志部件局部变形。
- 阴影：`scaleX/Y`、`opacity`；角色上升时阴影缩小并变淡。
- 道具：位置、旋转、缩放、显隐和状态替换。
- 特效：只使用星点、方块、叶片、纸条、柔软波纹五类。
- UI 与字幕不跟随角色进行弹跳或旋转，避免影响阅读。

## 3. 产品状态和动作抢占

### 3.1 产品状态

| 当前状态 | 到桌面陪伴 | 到快捷互动 | 到学习冒险 | 到安静陪伴 |
|---|---|---|---|---|
| `DESKTOP_ACTIVE` | 保持 | 允许：展开快捷卡 | 间接：先展开快捷卡再扩展玩具盒 | 允许：完成当前直接互动后进入 |
| `QUICK_INTERACTION` | 允许：收起快捷卡 | 保持 | 允许：同一窗口扩展 | 允许：先收卡再进入 |
| `LEARNING_ADVENTURE` | 允许：保存检查点后关闭 | 间接：固定执行 `ui.toybox_to_desktop`，完成后再执行 `ui.desktop_to_quick` | 保持 | 允许：保存检查点后关闭 |
| `QUIET_COMPANION` | 允许：孩子主动唤醒 | 允许：仅孩子主动点击 | 间接：主动点击后经快捷卡进入 | 保持 |

- 任一时刻只存在一个宠物实例和一个交互窗口实例。
- 状态转换期间的重复点击被合并为一次，不反向播放过渡。
- 学习任务进行中禁止因超时自动收缩。

### 3.2 优先级

| 优先级 | 名称 | 示例 |
|---:|---|---|
| P0 | `SYSTEM_SAFE` | 退出、失焦、指针捕获丢失、显示器断开、系统休眠 |
| P1 | `DIRECT_INPUT` | 拖拽、放下、任务对象操作 |
| P2 | `TASK_RESULT` | 错误、提示、成功、理解复述 |
| P3 | `STATE_TRANSITION` | 快捷卡、玩具盒、安静模式切换 |
| P4 | `AMBIENT` | 待机、移动、睡眠、彩蛋 |

- 高优先级可以抢占低优先级。
- 队列最多保留一个 P1–P3 语义动作；P4 不入队。
- `SYSTEM_SAFE` 立即跳到动作定义的安全结束姿势，并清理粒子、道具、字幕和点击锁。
- 同时产生提示与成功时，成功优先，提示取消。
- 完成记录、纪念物和学习状态写入必须幂等；动画重复触发不能重复写入。

### 3.3 中断标记

- `I`：任意帧可立即中断。
- `M:Fxx`：只能在指定帧或其后的下一个安全标记中断。
- `N`：不可中断；首版不可中断段不得超过 60 帧。
- 中断后若无单独说明，150 ms 内淡出临时特效，道具回到最近有效状态，角色落到 `idle` 首帧。

## 4. 角色动作时间轴

### 4.1 尾尾｜星尾猫

#### `motion.weiwei.idle`

- 总帧：72；循环：`F00–F71`；触发：6 秒无交互；优先级：P4；中断：I；结束：四爪着地、尾尖朝外。
- `F00–F11`：身体保持 100%，尾巴由 0° 缓慢摆到 +4°，眼睛看前方，阴影不变；`ease-in-out`。
- `F12–F23`：胸腹扩大到 103%，耳尖上抬 2 px，尾尖星星逆时针转 4°；`ease-out`。
- `F24–F35`：胸腹回到 100%，尾巴穿过中点到 -4°；`ease-in-out`。
- `F36–F47`：眼睛向最近光标方向移动不超过瞳孔半径 35%，右耳轻转 5°；无光标时保持前视。
- `F48–F59`：眨眼；F48–F51 上眼睑闭合，F52–F55 `hold`，F56–F59 打开。
- `F60–F71`：尾巴和耳朵回到 F00；不播放音效或粒子。
- Reduced motion：保持 F00，仅每 4 秒眨眼一次。

#### `motion.weiwei.move`

- 总帧：24；循环：`F00–F23`；触发：桌面目标点变化；P4；中断：I；结束：最近完整着地帧。
- `F00–F05`：左前爪和右后爪前摆，身体下降 2 px，尾巴反向摆 6°；`ease-in-out`。
- `F06–F11`：两组爪交叉通过，身体前移一个四分之一步幅并回升 2 px。
- `F12–F17`：右前爪和左后爪前摆，身体下降 2 px，尾巴换向。
- `F18–F23`：回到对称着地姿势，完成一个步幅；软阴影水平移动但不缩放。
- 音画事件：F05、F17 可触发极轻毛毡脚步声；桌面安静模式禁用。
- Reduced motion：角色以线性位移滑到目标，尾巴不摆动。

#### `motion.weiwei.sleep_wake`

- 总帧：96；循环：`F24–F71`；触发：安静 8 分钟或进入安静陪伴；P4/P3；中断：进入段 M:F18，循环 I，醒来段 N；结束：F95 站立。
- `F00–F11`：前腿弯曲、身体下降 6 px，尾巴从外侧绕向身体；`ease-out`。
- `F12–F23`：身体缩成团，星尾覆盖前爪，眼睑闭合；F20 出现一枚小纸片月亮后淡出。
- `F24–F47`：睡眠吸气，身体到 102%，尾尖上浮 2 px，阴影扩大 2%。
- `F48–F71`：呼气回到 100%，尾尖下落；只有 `F24–F71` 循环。
- `F72–F83`：收到唤醒后耳朵先竖起，眼睛仍闭；尾巴松开。
- `F84–F95`：眼睛打开，身体起立并轻伸展，回到站立。
- 音画事件：F16 轻哈欠；睡眠循环无鼾声。
- Reduced motion：F00 淡到蜷缩静态姿势；唤醒时交叉淡到 F95。

#### `motion.weiwei.notice_observe`

- 总帧：24；不循环；触发：悬停 400 ms 或任务线索出现；P4/P2；中断：M:F08；结束：视线停在目标 0.5 秒后回 idle。
- `F00–F05`：耳朵向目标侧依次竖起，先近耳后远耳。
- `F06–F11`：头部转向目标最多 12°，瞳孔移动到目标方向；尾巴停止待机摆动。
- `F12–F17`：身体前倾 4°，尾尖星星缩放到 108% 后回 100%。
- `F18–F23`：保持观察姿势；任务线索在 F18 触发一次橙色虚线呼吸。
- Reduced motion：直接切换为 F18 静态观察姿势。

#### `motion.weiwei.touch_response`

- 总帧：30；不循环；触发：头部单击；P1；中断：M:F12；冷却：1.2 秒；结束：站立。
- `F00–F05`：头顶被压低 3 px，耳朵向两侧展开，身体 `scaleY 97%`。
- `F06–F11`：闭眼，身体回弹到 `scaleY 103%`，尾巴向上弹 8°。
- `F12–F17`：一枚暖黄星点从尾尖上升 8 px并淡出；播放短毛毡“扑”声。
- `F18–F23`：眼睛打开，尾巴回落。
- `F24–F29`：姿势回到 idle；重复点击只延长 F12 `hold`，不重开动作。
- Reduced motion：闭眼微笑姿势保持 300 ms，星点不移动只淡入淡出。

#### `motion.weiwei.drag_release`

- 总帧：48；保持：`F12–F29`；触发：拖拽超过 4 px；P1；中断：P0 可立即中断；结束：有效落点站立或无效落点原位。
- `F00–F05`：获得指针捕获，四爪离地 3 px，身体纵向拉长到 104%，阴影缩到 80%。
- `F06–F11`：身体左右轻晃各 3°，尾巴垂下并滞后 2 帧。
- `F12–F29`：拖拽保持段；角色中心跟随指针，最大滞后 24 px；身体朝速度反向旋转不超过 6°；此段按需要 `hold`。
- `F30–F35`：释放；角色向安全落点移动，尾巴先到、身体后到；无效落点使用上一个有效位置。
- `F36–F41`：着地压缩到 `scaleY 94% / scaleX 104%`，阴影恢复到 110%。
- `F42–F47`：回弹到 100%，释放指针捕获；F47 发 `drag.complete`。
- Reduced motion：拖拽实时跟随；释放时 120 ms 线性定位，无拉伸和回弹。

#### `motion.weiwei.item_use`

- 总帧：48；不循环；触发：收到词卡、书页或通用物品；P1/P2；中断：M:F18；结束：物品进入目标槽或返回材料区。
- `F00–F07`：头转向物品，前爪抬起，`item_anchor` 激活。
- `F08–F15`：双爪接住物品，物品缩放 96% 表示接触。
- `F16–F27`：物品移到胸前；尾尾低头观察，眼睛从左扫到右。
- `F28–F35`：根据结果抬头并将物品指向操作区；F32 发 `item.inspected`。
- `F36–F43`：物品移动至目标槽；纸条粒子 2 枚，持续不超过 8 帧。
- `F44–F47`：前爪放下，回到站立。
- Reduced motion：物品在接手点和目标槽之间交叉淡变。

#### `motion.weiwei.think`

- 总帧：48；不循环；触发：宠物尝试前或等待孩子判断；P2；中断：M:F24；结束：尾巴问号姿势。
- `F00–F07`：坐下，眼睛看向左上，尾巴由直线开始卷曲。
- `F08–F15`：尾巴形成半问号，瞳孔变为逗号形。
- `F16–F23`：尾巴完成问号轮廓，尾尖星星停在头顶右上。
- `F24–F31`：出现一个奶油色思考泡泡，内部仅放当前线索图标，不放答案。
- `F32–F39`：泡泡轻缩放 100%→104%→100%，尾尾看向孩子。
- `F40–F47`：泡泡保持，F44 发 `help.requested`；等待后续动作抢占。
- Reduced motion：直接显示 F32 姿势与静态泡泡。

#### `motion.weiwei.safe_fail_retry`

- 总帧：42；不循环；触发：任务结果与预期不符；P2；中断：M:F24；结束：好奇前倾姿势。
- `F00–F05`：错误对象先产生可见结果；尾尾耳朵一前一后，身体停住。
- `F06–F11`：尾巴问号轻歪 8°，眼睛在结果与原材料间移动。
- `F12–F17`：用一只爪遮住半张纸，嘴型为小横线；不低头、不流泪。
- `F18–F23`：从爪后探头，耳朵重新竖起。
- `F24–F31`：把纸放回操作区并指向一个线索；橙色虚线只呼吸一次。
- `F32–F41`：身体前倾、尾巴打开，字幕可显示“再看看这里”；F36 发 `retry.ready`。
- Reduced motion：从观察错误结果直接切换到 F32 静态姿势。

#### `motion.weiwei.understand_restate`

- 总帧：54；不循环；触发：场景结果已提交后；P2；中断：M:F36；结束：指向方法或纪念物。
- `F00–F07`：眼睛从结果移到关键步骤，耳朵同时竖起。
- `F08–F15`：尾尖星星点亮到 120%，身体向上轻弹 3 px。
- `F16–F23`：尾巴沿关键对象画一条纸带轨迹，纸带顺序对应方法步骤。

#### `motion.weiwei.word_sort`

### 4.2 格格｜方糖机器人

#### `motion.gege.idle`

- 总帧：72；循环：`F00–F71`；触发：6 秒无交互；P4；中断：I；结束：双脚吸附地面。
- `F00–F11`：身体保持，屏幕眼睛眨一次水平短线；天线向左 2°。
- `F12–F23`：机身上浮 1 px，四角圆度视觉增加，胸前第一格灯亮。
- `F24–F35`：机身回落，第二格灯亮、第一格灭。
- `F36–F47`：眼睛看向最近光标，第三格灯亮、第二格灭。

#### `motion.gege.ambient_curiosity`

- 总帧：42；不循环；触发：桌面无直接交互20～50秒后随机一次；P4；中断：I；冷却：20秒；结束：双脚吸附地面并回到 idle。
- `F00–F05`：天线先向左转6°，屏幕眼睛看向左侧；机身与阴影不移动。
- `F06–F11`：天线经过中点转到右侧6°，眼睛同步看向右侧；胸前第一格灯亮。
- `F12–F19`：左右手臂向外伸展8°，机身上浮2 px，双脚仍吸附；`ease-out`。
- `F20–F27`：机身轻向左、右各倾2°，胸前三格灯依次亮起；不播放声音或粒子。

## 6. 桌面容器与窗口时间轴

### 6.1 通用规则

- 桌面宠物、快捷卡和玩具盒始终复用同一个角色实例、业务状态和音频实例。
- 窗口过渡只动画 `transform`、`opacity`、圆角和裁切蒙版；Windows 原生窗口尺寸在动画开始前一次性调整到最终外框，内部面板再做视觉插值，避免逐帧调整窗口造成抖动。
- 过渡期间除“跳过/关闭”外，输入锁定；重复点击只合并，不反向播放。
- 每次过渡结束必须发唯一完成事件，业务逻辑不得以 `setTimeout` 猜测动画结束。
- 所有透明区域在最终帧恢复点击穿透；关闭后不得留下屏幕外透明窗口拦截点击。

- `BRIDGE_HELP_READY` 后退出，重进显示小芽递出预测贴的静态姿势。
- 预测后退出，保留预测贴，但仍不判正误。
- 每完成一个测试立即写入对应检查点；重进时只恢复已完成结果卡和下一个待测形态。
- `BRIDGE_COMPARED` 后退出，重进直接显示折扇桥应用终态。
- `BRIDGE_COMMITTED` 后不得重复写实验记录或叶片纪念物。

## 10. 中断、失焦和系统边界

### 10.1 重复触发

- 单击去抖：250 ms；摸头冷却：1.2 秒；悬停触发：进入热点400 ms，只在离开热点300 ms后才能再次触发。
- 每秒点击5次持续10秒时，角色最多播放一次直接回应，后续点击只延长安全 `hold`，不得把角色卡在中间帧。
- 待机同一时刻只允许一个动作；待机和彩蛋不进入动作队列。
- 同一错误重复发生时可以跳过错误动作的进入段，但必须保留可见后果和线索，不提高负面强度。

### 10.2 拖拽和指针捕获

- 拖拽开始必须调用指针捕获；移动期间禁用待机、点击回应和学习邀请。
- `pointerup`、`pointercancel`、`Esc`、`Alt+Tab`、窗口失焦和指针捕获丢失都进入同一 `drag.cancel_or_commit`。
- 有效落点提交；无效落点回最近有效位置；多显示器变化时先按系统工作区重新约束落点。
- 拖拽跨越不同 DPI 显示器时，逻辑位置先换算成目标显示器设备无关像素，再在下一渲染帧应用一次缩放，不能同时缩放两次。

### 10.3 失焦、最小化和休眠

- 快捷卡或玩具盒失焦后立即停止接收键盘；非关键动画在下一个安全标记暂停。
- 语音在失焦时150 ms内衰减停止；返回时不补播旧语音，字幕恢复为当前稳定状态。
- 最小化或完全遮挡后暂停渲染，或降到每秒1帧以内；恢复时直接显示最近稳定帧。
- 系统休眠前同步写入检查点；唤醒后不自动播放长动画、成功反馈或声音。
- 成功逻辑已提交但动画未完成时退出，重进显示成功终态，不重复奖励。

### 10.4 多屏、任务栏和 DPI

- 使用 Windows 工作区边界，不假设任务栏位于底部。
- 支持任务栏上、下、左、右和自动隐藏；宠物被重新约束位置时不播放失败动作。
- 支持100%、125%、150%、175%和200%缩放、负坐标显示器、主副屏互换和运行中断开显示器。
- 快捷卡始终从宠物所在显示器向可用空间更大的一侧展开。
- 容器安全区：宠物主体离工作区边缘至少16 px；卡片离工作区边缘至少12 px；主要操作目标不小于44×44 px，拖放目标建议不小于56×56 px。

### 10.5 音频和字幕

- 音乐、音效、语音分别可关闭；安静陪伴不主动发声。
- 所有承载信息的语音必须有同步字幕；字幕不能遮挡宠物眼睛、关键数量和拖放目标。
- 音频设备断开不影响动作逻辑；重新连接后不补播已错过声音。
- 声音事件使用 `sfx.*`、`voice.*` 命名，并与制作帧绑定。

### 10.6 减少动态效果

- 启动和运行中都读取 Windows 动画设置及应用内 `reduced_motion`。
- 运行中切换时，当前动画立即跳到其 Reduced motion 指定的安全静态姿势。
- 禁用弹跳、连续摇晃、大幅缩放、快速位移和所有循环粒子；拖拽仍保留实时跟随。
- 线索、失败、成功和复述仍必须通过位置、轮廓、图标、文字和终态差异表达。

## 11. 资产导出和程序事件

### 11.1 角色源文件

- 每只宠物使用512×512矢量母版，`ground_anchor` 坐标统一。
- 必备图层：`body`、`head`、`face_eye_l`、`face_eye_r`、`face_mouth`、`limb_*`、`signature_part`、`shadow`、`effect_front`、`effect_back`。
- 输出检查尺寸：128、96、64、48 px；48 px只保留主轮廓、眼睛、标志部件和两个主色。
- 动画源按24 fps制作；运行时允许60 fps插值，但逻辑事件必须读取事件轨而不是推算毫秒。
- 单只宠物完整动作包压缩后建议不超过8 MB；四只与共用特效合计不超过40 MB。

### 11.2 导出命名

```text
pet/{pet_id}/{motion_id}.anim
pet/{pet_id}/{motion_id}.events.json
pet/{pet_id}/{size}/atlas.webp
fx/{fx_id}.anim
scene/{scene_id}/{object_id}.asset
audio/sfx/{event_id}.ogg
audio/voice/{locale}/{event_id}.ogg
caption/{locale}/{event_id}.json
```

- `pet_id`：`weiwei`、`gege`、`xiaoya`、`tuantuan`。
- 动作 ID 使用本文 `motion.{pet_id}.{action}`，不得在代码中另建同义名称。
- 事件 ID 使用：
  - `ui.*`：窗口和容器；
  - `task.share.*`、`task.bridge.*`：任务检查点与完成；
  - `item.*`：道具；
  - `memory.*`：纪念物；
  - `sfx.*`、`voice.*`：音频；
  - `drag.*`：拖拽。

### 11.3 事件轨要求

每个 `.events.json` 至少包含：

```json
{
  "fps": 24,
  "totalFrames": 54,
  "loop": null,
  "interrupt": ["F36"],
  "events": [
    { "frame": 24, "name": "voice.method.start" },
    { "frame": 46, "name": "memory.commit.visual_done" }
  ],
  "reducedMotionPose": "F36"
}
```

- 字幕、音效、写入和输入解锁必须由事件轨触发。
- 数据写入事件与视觉完成事件必须分离；视觉可跳过，数据不能漏写。
- 所有任务对象的稳定状态必须可以从检查点直接重建，不依赖从第一帧重播。

## 12. 性能与验收

### 12.1 参考机预算

- 参考机：4核CPU、8 GB内存、集成显卡。
- 桌面待机5分钟平均CPU不高于1.5%，P95不高于3%，GPU不高于3%。
- 桌面态工作集建议不高于200 MB；打开玩具盒后建议不高于350 MB。
- 活动动画目标60 fps，持续帧率不低于55 fps；主线程不得出现超过100 ms的动画阻塞。
- 单张纹理图集不超过2048×2048；玩具盒常驻纹理显存建议不超过64 MB。
- 首屏只加载当前宠物基础动作；其他宠物、背景和专属动作按需加载。

### 12.2 机械自检

- 角色动作：4只×13组，共52个唯一 `motion.*` ID。
- 基础动作：每只10组；专属学习动作：每只3组。
- 产品状态：4种；状态转换矩阵：16格均有定义。
- 容器动作：桌面、快捷卡、任务板、栖息站之间共8组时间轴。
- 粒子：星点、方块、叶片、纸条、柔软波纹共5类。
- 纵向切片：格格分果子、小芽纸桥实验共2个；均包含问题、错误/预测、求助、操作、结果、复述和纪念物。
- 所有自动片段均有总帧、连续帧区间、结束事件和 Reduced motion。
- 所有学习任务均在自动片段后停住等待孩子，不连续自动播放。

### 12.3 必测边界

1. 拖拽宠物跨越125%与200%缩放的两台显示器时，副屏突然断开。
2. 拖拽中按 `Alt+Tab`，系统未发送正常释放事件。
3. 快捷卡扩展中连续双击宠物并按 `Esc`。
4. 任务成功、纪念物动画未完成时应用关闭或电脑休眠。
5. 错误动画中同时点击提示与正确操作。
6. 动画中途开启减少动态效果。
7. 宠物位于副屏角落时改变任务栏方向或自动隐藏设置。
8. 语音中途拔出并重新连接音频设备。
9. 玩具盒失焦后在其他软件输入，宠物不得继续监听。
10. 安静陪伴、系统唤醒和待机彩蛋同时满足时，只保留系统安全与安静状态。

## 13. 后续制作门槛

- 在52组动作ID、两个任务检查点和程序事件命名冻结前，不进入完整角色动画生产。
- 第一轮只制作尾尾和格格的64/96/128 px动作可读性测试，以及“格格分果子”的完整纵向切片。
- 第一轮通过后再制作小芽纸桥实验；团团情绪场景需要单独做儿童理解测试后进入生产。
- 任何新增动作必须说明现有52组为什么无法组合表达；否则使用现有动作、道具覆盖层和程序参数完成。
