# Pi discovery implementation notes

本课程遵循根目录 `CLAUDE.md` 中已获用户确认的独立探索系列约定，以及 `docs/pi-discovery-design.md`；只修改本课请求涉及的内容。页面模型、样式与交互独立，双语陪伴稿不进入网页运行依赖。

## 已犯错误（禁止重犯）

- **2026-09-08**：探索版虽然视觉精致，但把测量、数列与计算压缩成控件和结果，缺少生活场景与动作因果。用户确认改为八场动态几何叙事；绳子必须经过指边、绕圈、标记、保长展开、取直径、逐根比较，不能一键跳到比值。此改造仍使用本目录现有文件；分镜与来源放在 `docs/pi-discovery-design.md`，截图仅存系统临时目录。

- **2026-09-08**：SVG 场景显隐误用了 HTML 元素的 `hidden` 属性写法；SVG 必须显式增删 `hidden` attribute 并配合 CSS。已改正，并通过浏览器检查每幕只有一个主场景可见。
- **2026-09-08**：禁用主按钮时，背景过渡仍在运行，深色禁用文字短暂落在深蓝背景上；禁用导航的文字对比度也略低于要求。已为全部禁用状态明确前景/背景并停止过渡，加入即时计算样式的对比度验证。不能只凭静态截图判断按钮状态。
- **2026-09-08**：局部放大窗的取景和继承线宽导致只看见一条外边。已调整焦点并单独指定缩放后线宽；放大图必须与实际图形对应且同时显示要比较的证据。
