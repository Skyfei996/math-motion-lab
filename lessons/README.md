# 课程目录约定

`周长不变形状变/` 是「几何画布」自由拼线段工具：可输入任意正数长度并持续添加独立线段；每个 32 像素网格代表 1 厘米，滚轮或触控板滚动平移视野，Ctrl＋滚动或右下角缩放控件缩放（25%～400%），「适应」一览全部内容，图形不会自动缩小。「连线」模式下抓住端点拖出即可补一条线段并吸附到其他端点。选中对象可「保存图形」进素材库（localStorage 持久化），从「素材库」直接放入；「更多」菜单含复制、粘贴、保存整张画布、清空画布、返回目录和语言切换。工具栏「快捷键 ?」列出键位；N、Shift+N 添加线段或图形，1／2／3 切换工具，Ctrl+A／C／V／Z 对应全选、复制、粘贴、撤回，输入框和中文输入法组合期间不会触发画布快捷键。图形名称与周长在画布下方的窄状态栏显示，错误提示也在此显示；画布内不再弹出说明。颜色、线宽等外观设置收进「样式」面板。尺寸弹窗可批量添加正方形、长方形、三角形、梯形、圆和椭圆。线身支持单条或相连整组移动，空白处拖框多选，Delete 或按钮删除选中对象；端点沿线拖动可伸缩线段，斜向拖动可旋转并带动已连接线段。支持撤回；可从 10 种常用颜色选择或自定义颜色，并调整线宽、端点大小、实线或虚线。闭合图形显示周长，圆和椭圆显示近似周长。几何计算在 `../assets/lab-models.js`，双语讲稿在同一目录，设计与验收范围见 `../docs/perimeter-shape-design.md`。

「保存整张画布」先填写名称；取消或输入空名称不会保存。素材库中的「改名」可修改已保存条目的名称，名称随条目保存在 localStorage 中。

「点击拆分」（或按 4）可在线段内部点击生成新端点，随后在「连线」模式从该点画线。选中单条线段后，从「更多 → 按长度拆分」可输入平均份数或用逗号分隔的各段长度；拆分前后总长度不变。按住 Shift 可逐条增减所选线段；同一直线上首尾相接、样式一致且中间无分支的多段，可从「更多 → 合并线段」或按 J 合为一段。X 打开所选线段的拆分弹窗。拆分与合并可撤回。

选中封闭的直边图形、圆或椭圆后，可在「样式」中从 10 色色板或自定义颜色设置填充，也可清除填充；共用边分出的多个封闭区域可点击内部，分别上色。填充随撤回、复制粘贴及素材库保存。拖动线身时按住 Ctrl，会按拖动开始时的主要方向锁定水平或垂直移动；连线时按住 Ctrl，长度吸附到整厘米；沿线段方向拖端点时按住 Ctrl，长度以 1 厘米为步长增减。松开 Ctrl 后恢复自由操作。

`pi-discovery/` 是《圆周率是怎么计算出来的》探索读物。目录内除课程页面、样式、脚本和双语讲稿外，包含独立 `models.js`。本课不复用旧课页面实现。设计、来源与验收记录在 `../docs/pi-discovery-design.md`；测试在 `../tests/pi-discovery-tests.js`。截图只写入系统临时目录，不纳入版本库；交付后不保留临时生成脚本到项目中。

新建或重新改造的题目使用一个以可读题目名称命名的文件夹，不使用难以识别的内部课程 ID 作为文件夹名。尚未改造的旧页面可在后续维护该题目时迁移。

```text
lessons/
  题目名称/
    index.html
    speaker-script.zh-CN.md
    speaker-script.en-US.md
    styles.css
    lesson.js
```

## 必需文件

- `index.html`：课程讲解页面。
- `speaker-script.zh-CN.md`：可打印的中文演讲稿。
- `speaker-script.en-US.md`：可打印的英文演讲稿。

## 可选文件

- `styles.css`：只服务于当前课程的样式。
- `lesson.js`：只服务于当前课程的页面交互和动画。

跨课程复用的数学模型、样式、数据和交互继续放在项目根目录的 `assets/` 中。

## 演讲稿格式

两份演讲稿必须与页面讲解步骤一一对应。每一步至少包含：

1. 页面操作。
2. 向学生提出的问题或停顿提示。
3. 老师可以直接照读的话术。
4. 页面应出现的关键数字或结论。

演讲稿不通过 `<script>`、`fetch` 或其他方式加载到网页中，只作为独立打印材料保存。

## 同步规则

以下改动必须同步检查并修改中英文演讲稿：

- 增加、删除或调整讲解步骤。
- 修改按钮名称或老师的操作顺序。
- 修改默认题目参数、计算公式或最优方案。
- 修改全大车、全小车或逐辆替换的判断方向。
- 修改最终答案或并列最低方案的表达方式。

完成后运行项目技能提供的检查：

```powershell
python .agents/skills/build-bilingual-math-lesson/scripts/validate_lesson_package.py "lessons/<题目名称>"
```
